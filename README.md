# 小猪 Clawd 桌宠

Windows 桌面小猪：自由走动和停驻、触摸耳朵/鼻子/肚子、画画、种花、浇水、摘花、送花、刷视频，以及可恢复的吃快捷方式。

## 本次修复：v1.0.2

基于 `sariel24/clawd-pig` 的 `0e49728`，续接未推送的 `381de25` 修复思路。用户电脑上 9 月 14 日那轮改动没有同步到该仓库；本分支不覆盖那份本机工程，也未修改原有 PNG。合并之前如有更新源码，应先比对。

- 面板的“走过去吃”和预览共用完整动作流程：定位 → 行走 → 闻/吞吃 → 仓库存储。播完吞吃动画才移动快捷方式。
- 拖动、触摸、取消真实移动、恢复全部，都能打断尚未吞下的操作。一次只吃一个，重复点击不再并发。
- 修正全局锚点与窗口内部偏移混用；气泡显示/隐藏或改变大小时保留小猪的桌面位置；走向图标时腿会动，停下后脚不再原地走。
- Windows 用异步 UI Automation 读取图标位置并转换为 DIP。无法识别真实位置或名称有歧义时，只允许路线预览，不移动真实图标。估算坐标不会冒充真实位置。
- 原生确认框控制真实移动；开关变化后刷新已有候选按钮；错误和操作进度直接显示在面板里。
- 消除挑食评分在一次进食中反复随机的问题；清单保存失败时不移动文件；同名恢复自动避让。

## 运行

安装 Node.js 22 LTS，在本项目目录运行：

```powershell
npm ci
npm start
```

右键小猪 → **图标功能（吃图标/种植）→ 打开图标仓库面板**。先点“扫描桌面候选”，再试“走过去预览”。需要真正吃图标时，勾选“允许真实移动”并确认。

“吃掉”只把当前用户桌面上的 `.lnk`、`.url` 移到用户数据目录的 `belly-storage`，可以种植、收获或一键恢复。照片、文档、文件夹、系统图标不会作为食物。恢复文件不保证 Explorer 恢复原来的图标排列。默认每日 3 个、有冷却时间；面板会说明暂时不能吃的原因。

## 验证与 Windows 安装包

```powershell
npm test
npm run check
npm run test:smoke
npm run dist
```

`test:smoke` 自行创建临时桌面和独立配置目录，不会拿真实桌面进行测试。测试包含面板开关、行走、最后一口才移动、取消、同名恢复和损坏清单恢复。

GitHub Actions 的 **Build Windows Installers** 可手动运行，推送 `fix/**`、`feature/**` 和 `main` 的代码改动也会触发。工作流先运行测试，再生成 x64 的 NSIS 安装版和 Portable 便携版。产物在该次运行的 `clawd-pig-windows-x64` 附件中；不签名、不创建 Release。

2026-10-07 已上传到 `cshu3717-art/clawd-pig` 的 `fix/complete-icon-interactions` 分支，Windows 自动测试 40/40 通过，NSIS 与 Portable 构建成功：[构建记录与安装包](https://github.com/cshu3717-art/clawd-pig/actions/runs/37631198723)。在页面底部 **Artifacts** 点击 **clawd-pig-windows-x64** 下载，解压后选择 `Setup` 安装版或 `Portable` 免安装版。该次产物保留至 2026-11-06，之后可重新运行工作流。
