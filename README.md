# 小猪 Clawd 桌宠

Windows 桌面小猪：自由走动和停驻、触摸耳朵/鼻子/肚子、画画、种花、浇水、摘花、送花、刷视频，以及可恢复的吃快捷方式。

## 本次更新：v1.2.1

- **屏幕变化后自动找回小猪**：拔插显示器、调整分辨率、缩放、旋转或任务栏工作区后，小猪与仓库面板重新约束到可见区域。原来就能看见的小猪保持原位，左侧或上方副屏的负坐标仍然有效。
- **停止旧路线和旧拖动**：屏幕改变时取消追逐、尚未吞下的图标、播种与怒气批次；已经吃下的快捷方式仍在仓库中。旧坐标请求不能把小猪拉回消失的屏幕。
- **位置恢复后保持一致**：主窗口、身体锚点和存档同步更新；气泡收起、重新加载或连续屏幕事件后不回跳。超大装饰画布优先保留小猪身体，小工作区里的面板保留可抓取的标题栏。

### 延续的 v1.2.0 功能

- **首次打开有三步引导**：选城市 → 试着摸摸小猪 → 开始陪伴。可以跳过天气或稍后再设置，完成后不再自动弹出；右键菜单或仓库面板可以重新打开。
- **引导能处理断网与保存失败**：城市保存成功即可继续，不需要等天气查询成功；保存失败会留下明确提示并保留当前步骤。互动按钮会让桌面上的小猪真正回应，忙碌时会提示稍等。
- **配饰跟随全部专用动作**：种花、浇水、画画、看手机，以及吃图标、嫌弃、播种的 40 个动作格都按身体位置与倾角绘制服饰。围巾让手机、花洒和画笔显示在前面；调整大小或朝向时与身体一起变化。
- **小窗口也能操作引导**：下方的上一步、跳过、下一步保持可见，城市设置区域独立滚动。
- **修正跨格残影**：完整保留吃图标动画的脚尖和快捷方式边缘，清掉下一帧带出的上一排道具；原始图片保持不变。

### 延续的 v1.1.0 功能

- **种植可以可靠地取消和重试**：播种动画全部完成后才记录为“已种好”；占用时拒绝重复操作；取消、恢复或保存失败不会留下假成功状态。
- **怒气温度计与追图标**：揪耳朵增加 25 点，摸肚子减少 15 点，碰鼻子减少 8 点；安静后逐渐消气。满 100 后逐个走近并吃最多 5 个不同图标，可以触摸、拖动或用面板停止。重新启动不会自动发怒。
- **天气换装**：右键 →“天气与换装（选择城市）”，搜索并核对城市、省份和国家。支持雨帽、雪天/寒冷围巾帽、晴天帽、风天围巾、夜帽、多云围巾。

怒气开关默认开启，但真实文件移动仍由“允许真实移动”控制。不开启时只演示；开启时，怒气批次与日常每日 3 个的进食额度分开计算，每轮最多 5 个，至少间隔 90 秒。所有吃下的快捷方式都保存在仓库中，支持一键恢复。

天气由 [Open-Meteo](https://open-meteo.com/) 提供模型估计，城市搜索数据来自 [GeoNames](https://www.geonames.org/)。只发送手选城市的名称或经纬度，不请求设备精确定位。每 30 分钟查询，手动刷新最短间隔 1 分钟；断网明确显示旧数据，缓存超过 3 小时便卸下配饰。可关闭查询，城市选择保存在本机。接口说明：[天气](https://open-meteo.com/en/docs)、[城市搜索](https://open-meteo.com/en/docs/geocoding-api)。

- 拖动、触摸、取消真实移动、恢复全部，都能打断尚未吞下的操作。一次只吃一个，重复点击不再并发。
- 修正全局锚点与窗口内部偏移混用；气泡显示/隐藏或改变大小时保留小猪的桌面位置；走向图标时腿会动，停下后脚不再原地走。

- 原生确认框控制真实移动；开关变化后刷新已有候选按钮；错误和操作进度直接显示在面板里。
- 消除挑食评分在一次进食中反复随机的问题；清单保存失败时不移动文件；同名恢复自动避让。

## 运行

安装 Node.js 22 LTS，在本项目目录运行：

```powershell
npm ci
npm start
```

右键小猪 → **图标功能（吃图标/种植）→ 打开图标仓库面板**。先点“扫描桌面候选”，再试“走过去预览”。需要真正吃图标时，勾选“允许真实移动”并确认。

“吃掉”只把当前用户桌面上的 `.lnk`、`.url` 移到用户数据目录的 `belly-storage`，可以种植、收获或一键恢复。照片、文档、文件夹、系统图标不会作为食物。恢复文件不保证 Explorer 恢复原来的图标排列。默认每日 3 个、有冷却时间；面板会说明暂时不能吃的原因。

## 验证与 Windows 安装包

```powershell
npm test
npm run check
npm run test:smoke
npm run test:setup
npm run test:displays
npm run dist
```

`test:smoke` 自行创建临时桌面和独立配置目录，不会拿真实桌面进行测试。测试包含面板开关、行走、最后一口才移动、取消、同名恢复和损坏清单恢复。

`test:setup` 验证三步引导、跳过天气、离线选城、保存失败重试、手动重开和持久化状态；Windows 还验证首次自动弹出、两个窗口间的真实互动，以及完成后只关闭引导窗口。

`test:displays` 在真实 Electron 窗口中模拟屏幕拓扑变化，检查位置恢复、旧坐标拒绝、拖动释放、气泡与存档同步，以及追逐/吞吃/播种/怒气取消后的文件完整性。Windows 还检查仓库面板恢复。这里使用合成工作区，不能替代实际显示器拔插和混合 DPI 测试。

GitHub Actions 的 **Build Windows Installers** 可手动运行，推送 `fix/**`、`feature/**` 和 `main` 的代码改动也会触发。工作流先运行测试，再生成 x64 的 NSIS 安装版和 Portable 便携版。产物在该次运行的 `clawd-pig-windows-x64` 附件中；不签名、不创建 Release。

代码更新在 `cshu3717-art/clawd-pig` 的 `fix/complete-icon-interactions` 分支。[打开该分支的 Windows 构建](https://github.com/cshu3717-art/clawd-pig/actions/workflows/build-windows.yml?query=branch%3Afix%2Fcomplete-icon-interactions)，选择最近一次成功运行，在页面底部 **Artifacts** 点击 **clawd-pig-windows-x64** 下载，解压后选择 `Setup` 安装版或 `Portable` 免安装版。安装包保留 30 天，可重新运行工作流。
